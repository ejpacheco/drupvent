|---|---|
| [01-entorno.md](01-entorno.md) | Versiones, entorno local y forma de trabajar con la configuración |

## Convenciones de esta carpeta

- Cada documento indica su estado: **Implementado**, **Propuesta** o **Pendiente**.
- Cuando se implementa algo, se actualiza su documento y se añade una entrada en la [bitácora](bitacora.md).
- Las decisiones se registran en [02-decisiones.md](02-decisiones.md) con su fecha y su motivo.
